WEBSITE ULANG TAHUN — TANPA FOTO

Cara pakai:
1. Extract ZIP.
2. Upload semua isi folder ke repository GitHub.
3. Pastikan index.html berada di root repository.
4. Jika memakai GitHub Pages: Settings > Pages > Deploy from branch > main > /(root).
5. Buka URL GitHub Pages milikmu.

Website ini sengaja tidak memakai foto, sehingga lebih ringan dan aman untuk di-upload.
